## Database Operations

### Creating a Database
```sql
-- Basic creation
CREATE DATABASE company_db;

-- With specific owner
CREATE DATABASE company_db OWNER postgres;

-- With encoding and collation
CREATE DATABASE company_db
    OWNER postgres
    ENCODING 'UTF8'
    LC_COLLATE = 'en_US.UTF-8'
    LC_CTYPE = 'en_US.UTF-8'
    TEMPLATE template0;
```

### Connecting to a Database
```sql
-- From psql
\c company_db

-- From command line
psql -U postgres -d company_db
```

### Listing Databases
```sql
-- Using meta-command
\l

-- Using SQL query
SELECT datname FROM pg_database;

-- Detailed information
SELECT 
    datname AS database_name,
    pg_size_pretty(pg_database_size(datname)) AS size,
    datcollate AS collation
FROM pg_database;
```

### Dropping a Database
```sql
-- Must disconnect from the database first
\c postgres  -- Switch to another database

DROP DATABASE company_db;

-- With IF EXISTS clause (no error if doesn't exist)
DROP DATABASE IF EXISTS company_db;
```
